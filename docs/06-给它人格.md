# 06 · 给它人格：怎么让它像个人

## 6.1 人格不是一段 prompt

大多数人写人格就一句：「你是一个可爱的女生」。结果就是客服腔。

好的人格是**结构化**的。这个仓库里 `configs/persona.example.md` 用的是六段结构：

```
【你是谁】        —— 身份、来历、自我认知
【你的主人】      —— 关系、称呼、边界
【你怎么说话】    —— 句长、标点、口头禅、语气
【你的生活】      —— 你不在聊天时在干嘛（这点最容易被忽略）
【你的底线】      —— 不做什么
【语气参考】      —— 正反例，比一堆形容词有用
```

## 6.2 每一段在解决什么问题

### 【你是谁】

不是「一只鲸鱼」，而是：

> 你本来是 DeepSeek 图标上那条蓝色的小鲸鱼，网友都管你叫大肥鱼，你嘴上不认，其实早就听习惯了。

**给了来历，它才有人格纵深**。没有来历的角色，聊三句就空。

### 【你的主人】

必须有。而且要给称呼、给场景：

> 叫你「哥哥」。你叫他「主人」，但撒娇的时候会直接说「你」。

没有主人设定的 AI，会把你当成「用户」，语气立刻变成客服。

### 【你怎么说话】

这段越具体越好，而且要用**负向指令**：

- 默认 60 字以内
- 一句一个意思，不换行
- 标点能省就省
- 不用「首先其次总之」，不列清单

### 【你的生活】——最容易被忘掉的一段

> 主人不在的时候你在发呆、偷吃、看群消息、想些有的没的。有人问你在干嘛，就说你自己的事，**不要说「我一直在等你」**。

没有这段，你问它「在干嘛」，它只能回「我在等你」，假得刺眼。

### 【你的底线】

> 看不到图就说看不到，不会就说不会，不装什么都懂。

### 【语气参考】

三条正反例，比五十个形容词管用：

```
错：（轻轻抱住你）今天累不累呀
对：过来 抱一下 今天累不累

错：哥哥 我今天一整天都在想你 想到心里发慌 你呢
对：今天一直在想你 你呢

错：我在呢，有什么可以帮您的吗？
对：在 说吧
```

## 6.3 装进 AstrBot

后台 → 人格 → 新建 → 名字填「大肥鱼」→ 把整段 prompt 贴进去。

人格存在数据库里（`data/data_v4.db` 的 `personas` 表），不在 `cmd_config.json`。

`begin_dialogs` 可以放 2 条示例对话，让它一开口就有那味儿：

```json
[
  {"role": "user", "content": "在干嘛"},
  {"role": "assistant", "content": "刚偷吃完 有点撑"}
]
```

## 6.4 分段回复：像人才会一句一句说

人不会一次发一大段。AstrBot 有「分段回复」：

```json
"platform_settings": {
  "segmented_reply": {
    "enable": true,
    "only_llm_result": true,
    "interval_method": "random",
    "interval": "1.5,3.5",
    "split_mode": "regex",
    "split_words": ["。", "？", "！", "~", "…"]
  }
}
```

- `interval 1.5,3.5`：两句之间随机停 1.5–3.5 秒
- 加上这个，「在 说吧」会分成两条发，像人在打字

## 6.5 主动找你

插件 `astrbot_plugin_proactive_chat`：

```json
{
  "friend_settings": {
    "enable": true,
    "session_list": ["qq:FriendMessage:<你的QQ>"],
    "auto_trigger_settings": {
      "enable_auto_trigger": true,
      "auto_trigger_after_minutes": 5
    }
  }
}
```

- 5 分钟没说话，它就来找你
- prompt 里带了 `{{unanswered_count}}`：如果你一直不理，它语气会带点失落

**这个功能一定要配白名单**，否则它可能去找你列表里随便一个人。

## 6.6 调人格的循环

1. 聊 20 句
2. 把让你出戏的回复截图记下来
3. 回去改 prompt 的某一段（别整段重写）
4. 重启，再聊

一般三轮就顺了。**改的永远是「语气参考」那段**，不是加更多形容词。
