# 08 · 安全护栏：只让它认你一个人

## 8.1 这一步为什么最重要

一个能被程序驱动的 QQ 号，等于**一个 24 小时在线的自动回复机**。没有护栏的话：

- 谁加它都能聊，烧你的 token
- 它可能被拉进群，在群里乱说话
- 最坏的情况：它带「操作电脑」的能力，被人利用

所以装完必须先做这一步。

## 8.2 只允许你的号私聊

后台 → 配置 → 安全 → 白名单：

```
qq:FriendMessage:1071675952
```

格式是 **平台:消息类型:对象ID**：

| 部分 | 例子 | 说明 |
|---|---|---|
| 平台 | `qq` | 平台适配器的 id |
| 消息类型 | `FriendMessage` | `FriendMessage` 私聊 / `GroupMessage` 群聊 |
| 对象ID | 你的 QQ 号 | 私聊就是对方 QQ |

**只加一条私聊白名单 = 全互联网只有你能跟它说话。**

多个的话用逗号分隔：

```
qq:FriendMessage:1071675952,qq:GroupMessage:123456789
```

## 8.3 管理员

后台 → 配置 → 管理员：

```json
"admins_id": ["1071675952"]
```

管理员能：

- 用 `/` 开头的指令
- 让它改签名、唱歌、发空间
- 触发重启、重载配置

**管理员和对话白名单是两件事**：白名单管「谁能聊」，管理员管「谁能命令」。

## 8.4 关掉「操作电脑」

AstrBot 有个工具调用能力，能让它执行命令、读写文件。

在 `cmd_config.json`：

```json
"provider_settings": {
  "computer_use_runtime": "none"
}
```

或者后台 → 工具 → 全部关掉（已开启工具数 = 0）。

**这是硬红线**：一旦它能执行命令，配合上面任何一条护栏被绕过，后果都是你的电脑。

## 8.5 改密码

装完立刻改三处：

| 是什么 | 默认值 | 改成 |
|---|---|---|
| AstrBot 后台 | `astrbot` / `astrbot` | 16 位随机 |
| NapCat WebUI | 首次启动给的 token | 保留随机 |
| 反向 WS token | 无 | 32 位随机 |

生成随机密码：

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(12))"
python3 -c "import secrets; print(secrets.token_hex(16))"
```

## 8.6 凭据放哪

建一个 `secrets/` 目录（和仓库同级，不进 git）：

```
secrets/
├── 机器人凭据.txt   # 后台地址/账号/密码、NapCat token、WS token
├── deepseek.txt
├── 豆包语音.txt
└── 硅基流动.txt
```

给 Agent 用的时候，让它**读文件**，不要在对话里打印。

## 8.7 最后一道：不暴露到公网

- 三个端口全部只监听 `127.0.0.1`
- 不做端口转发
- 家里路由不要 DMZ

要远程用，走内网穿透 + 鉴权，别直接开。

## 8.8 自检清单

```bash
bash scripts/check_env.sh --security
```

会检查：

- [ ] 白名单非空，且只有你的号
- [ ] 管理员是你的号
- [ ] `computer_use_runtime` 是 `none`
- [ ] 已开启工具数 = 0
- [ ] 后台密码不是默认值
