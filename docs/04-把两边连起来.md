# 04 · 把 NapCat 和 AstrBot 连起来

两边通过 **反向 WebSocket** 连：AstrBot 开一个端口等着，NapCat 主动连过去。

## 4.1 为什么是「反向」

正常 WebSocket 是客户端连服务端。这里反过来：

- AstrBot 监听 `127.0.0.1:6199`
- NapCat 作为客户端，连到 `ws://127.0.0.1:6199/ws`

好处是**端口只开在本地**，不用暴露在任何网卡上。

## 4.2 AstrBot 侧配置

后台 → 平台适配器 → 添加 `aiocqhttp`：

| 字段 | 填什么 |
|---|---|
| id | `qq`（随便） |
| 反向 WS 主机 | `127.0.0.1` |
| 反向 WS 端口 | `6199` |
| token（密钥） | **随机生成一串，记下来** |

随机 token 生成：

```bash
python3 -c "import secrets; print(secrets.token_hex(16))"
```

对应的 `cmd_config.json` 结构：

```json
"platform": [
  {
    "id": "qq",
    "type": "aiocqhttp",
    "enable": true,
    "ws_reverse_host": "127.0.0.1",
    "ws_reverse_port": 6199,
    "ws_reverse_token": "<你生成的token>"
  }
]
```

## 4.3 NapCat 侧配置

NapCat WebUI → 网络配置 → 新建 **WebSocket 客户端**（有的版本叫「反向 WS」）：

| 字段 | 填什么 |
|---|---|
| URL | `ws://127.0.0.1:6199/ws` |
| 消息格式 | `array`（默认）或 `string`，两个都支持 |
| Token | **和 AstrBot 那边填的一模一样** |
| 心跳 | 默认即可 |

保存后 NapCat 会立刻尝试连接。

## 4.4 验证连上了

AstrBot 日志里应该出现：

```
[aiocqhttp] websocket connected
[aiocqhttp] bot online: <小号QQ>
```

然后用**你的大号**私聊小号发一句「在吗」。

- 小号那边有回复 → 通了
- 没回复 → 看 09 的排障

## 4.5 连不上的四种情况

| 现象 | 原因 | 解法 |
|---|---|---|
| NapCat 一直重连 | token 不一致 | 两边逐字符对一遍，注意别带空格 |
| 连上但没消息 | 白名单拦了 | 文档 08，先确认你的号在 `id_whitelist` |
| AstrBot 报端口占用 | 6199 被别的进程占了 | `lsof -i :6199` 杀掉，或换端口 |
| 两边都正常但没反应 | 消息没触发 LLM | 后台看「控制台」有没有收到事件 |

## 4.6 一条规则：token 别复用

- NapCat WebUI 的 token：登录 NapCat 用
- AstrBot 反向 WS 的 token：两边连接用
- AstrBot 后台密码：登录后台用

**三个各自独立**，全随机。混用的话，一处泄露就全泄露。
