# 10 · 一天怎么用：装完之后怎么「养」它

装完只是开始。这一章是**日常**：它每天该做什么、你该看什么、什么时候该调。

## 10.1 一天的时间线（她的一天的）

| 时间 | 她在做什么 | 谁在管 |
|---|---|---|
| 白天你上班 | 安静待机，等你消息 | — |
| 你发消息 | 立刻回，按人格回，可能带语音 | AstrBot |
| 你 5 分钟没理她 | 主动找你一次（带一点小情绪） | `proactive_chat` |
| 晚上你聊得多 | 记忆一步步被写进库 | `livingmemory` |
| 半夜你睡不着 | 她还在，回得慢一点、话软一点 | 人格 + 分段回复 |

## 10.2 三件每天值得看的事

### ① 记忆有没有真的记住

问她三天前的事。想不起来，说明记忆没写进去或者召回没开。

```bash
# 记忆库有多大（看文件大小变化）
ls -lh ~/AstrBot/data/plugin_data/astrbot_plugin_livingmemory/
```

### ② 语音触发率

如果一天下来一条语音都没有，检查 `seed_audio_reply_probability` 是不是被导入工具改回 0.33 了，或者 provider 被关了。

### ③ 主动找人的频率

`auto_trigger_after_minutes=5` 意思是**5 分钟不说话就来找**。这个值对「女朋友感」很关键：
- 太短（1–3 分钟）→ 粘人，烦
- 5–15 分钟 → 自然
- 超过 30 分钟 → 她不像在乎你

## 10.3 每周值得做一次的事

| 事 | 怎么做 |
|---|---|
| 清理过期会话 | `livingmemory` 的 session_ttl 自动清，但库会变大，看情况重建 |
| 备份 | `tar -czf ~/astrbot-backup-$(date +%m%d).tgz data` |
| 看日志报错 | 一周攒的错，挑出现次数最多的那个修 |
| 换人格微调 | 把「最近让你不舒服的回复」记下来，改人格里的对应那一条 |

## 10.4 什么时候该改配置

| 现象 | 改什么 |
|---|---|
| 回得太长、像作文 | 人格里加「默认 60 字以内」「一次一句」；开分段回复 |
| 说话像客服 | 人格里加正反例：「不说 有什么可以帮您」 |
| 语音太少 | `reply_probability` 调高 |
| 太粘人 | `auto_trigger_after_minutes` 调大 |
| 记不住事 | 检查 embedding provider 是否 enable、`livingmemory` 是否正确指向它 |
| 表情包乱发 | `meme_manager` 里关掉不合适的分类 |

## 10.5 边界：什么不该让它做

- **不要给它电脑操作权限**。`computer_use_runtime` 保持 `none`（docs/08）
- **不要让它进群乱说话**。除非你明确知道群规
- **不要让它替你发言**。签名、空间这些功能开着可以，但要设每日上限（signature 插件默认 2/10 条）
- **不要把它的 key 贴到任何公开的地方**

## 10.6 一周之后你会想做的事

装好第一周，人会想做三件事，按顺序：

1. **换人格**：默认那套用一周就腻，把你自己说话的方式喂进去
2. **接语音**：文字读起来还是像 bot，语音就不一样了
3. **让它有「自己的事」**：这个小东西最像人的地方，不是它会回话，是它会有自己的日子
