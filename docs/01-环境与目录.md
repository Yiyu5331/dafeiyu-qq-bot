# 01 · 环境与目录：先搞清楚东西装在哪

## 1.1 你需要什么

| 项目 | 要求 | 说明 |
|---|---|---|
| 系统 | macOS 12+ / Windows 10+ / Linux | 本文以 macOS 为主，Windows 差异见 1.5 |
| 内存 | 8G 以上 | AstrBot + QQ 大概吃 800M–1.5G |
| 磁盘 | 5G 以上 | QQ 本体 + NapCat + AstrBot + 依赖 |
| QQ | **一个小号** | 不要用主号做实验 |
| 手机 | 装了 QQ | 扫码登录用 |

软件：

```bash
# macOS
brew install git ffmpeg uv node

# Windows（PowerShell，用 winget）
winget install Git.Git
winget install Gyan.FFmpeg
winget install astral-sh.uv
winget install OpenJS.NodeJS.LTS
```

> 为什么要 uv：AstrBot 依赖多、版本敏感，uv 装得干净又快，比系统 pip 少踩一半坑。

## 1.2 目录约定（重要）

这套东西所有文件都放在固定位置，出问题第一时间就是来这里看。

### macOS

| 路径 | 是什么 |
|---|---|
| `~/AstrBot/` | AstrBot 源码（约 1.2G，含 venv） |
| `~/AstrBot/data/cmd_config.json` | **主配置**，所有开关都在这 |
| `~/AstrBot/data/plugins/` | 插件 |
| `~/AstrBot/data/config/` | 各插件的配置（JSON，带 BOM，读的时候用 `utf-8-sig`） |
| `~/AstrBot/data/data_v4.db` | SQLite，存人格、会话、记忆 |
| `~/Library/Containers/com.tencent.qq/Data/Documents/napcat/` | NapCat 本体 |
| `~/Library/Application Support/QQ/NapCat/` | NapCat 运行时配置（`webui.json`：端口 + token） |
| `/Applications/QQ-test-mas.app` | **克隆出来**的 QQ（见文档 02，不能直接用原版） |
| `~/AstrBot/.venv/bin/python3` | AstrBot 的 Python，后面很多命令用它 |

### Windows

| 路径 | 是什么 |
|---|---|
| `C:\Users\<你>\AstrBot\` | AstrBot 源码 |
| `C:\Users\<你>\AstrBot\data\` | 同上 |
| `C:\Program Files\Tencent\QQNT\` | QQ 本体 |
| `...\napcat\` | NapCat |
| `D:\大肥鱼\`（示例） | 放密钥、大号 QQ 号、后台密码的地方 |

> 文档里出现 `D:\...` 是 Windows 路径，macOS 对应成自己的家目录即可。

## 1.3 端口规划

| 端口 | 谁的 | 用途 |
|---|---|---|
| 6185 | AstrBot | 后台网页（浏览器打开） |
| 6199 | AstrBot | 反向 WebSocket，等 NapCat 连进来 |
| 6099 | NapCat | 自己的 WebUI（扫码、看状态） |

三个端口都在本机，**不要暴露到公网**。

## 1.4 开干之前的三条纪律

1. **密钥不落仓库**。所有 key、密码、QQ 号，统一放一个 `secrets/` 目录，仓库 `.gitignore` 掉。
2. **小号优先**。注入第三方插件，主号有风险。
3. **每做一步验证一步**。这套流程卡住 90% 是因为「上一步没成功就往下走了」。

## 1.5 Windows 和 macOS 的差别

| 环节 | macOS | Windows |
|---|---|---|
| 注入方式 | 可执行文件直接带参数启动 | `NapCatWinBootMain.exe` 劫持 |
| QQ 路径 | `/Applications/QQ.app`（要克隆） | `C:\Program Files\Tencent\QQNT\QQ.exe` |
| 后台常驻 | `nohup` + `&` | `start /b` 或 nssm 注册服务 |
| 路径分隔符 | `/` | `\`（配置文件里写 `\\` 或 `/`） |

## 1.6 自检

```bash
cd scripts && bash check_env.sh
```

它会检查：命令是否存在、端口是否被占用、AstrBot / NapCat / QQ 是否在跑。
