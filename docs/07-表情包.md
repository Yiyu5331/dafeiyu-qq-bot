## 7.2 目录结构

```
packs/
└── blue-fat-fish-meme-pack/
    └── memes/
        ├── happy/
        │   ├── 0001_开心.gif
        │   └── ...
        ├── angry/
        └── ...
```

插件（`meme_manager`）会扫这个结构，按分类建索引。

## 7.3 在 QQ 里怎么用

配好之后有两种用法：

1. **自动**：插件判断当前对话情绪，自己挑一张发
2. **手动**：聊天里说「发表情」「来个生气的」，它去对应分类里找

## 7.4 为什么这套表情包不能拿去做视频

同一批 gif，在 QQ 里发没问题（小窗、300px 以内），但直接放到 1080 宽的视频画面里就完蛋：

- 500×500 放大到 1080 → 糊
- 大部分是**深色底或纯白底**，放大后一片黑/一片白
- 动图边缘有锯齿，放大更明显

正确做法（如果要做视频）是**当小贴纸**：≤240px、外面套白底圆角卡、别拉伸。

> 这条是这个坑踩了两次才总结出来的：第一版把 gif 拉到 600px 铺满右半屏，被骂「难看」。

## 7.5 自己加一套

1. 新建目录 `packs/my-pack/memes/<分类>/`
2. 往里丢 gif / png
3. 后台 → 插件 → meme_manager → 重新扫描

命名建议 `<序号>_<描述>.gif`，方便以后按名字精确调用。
